# 🧠 REGRAS DO JOGO (CLARAS PRA EDITAL)

Você pode colar isso no seu formulário:

### 🎯 Objetivo

Gerenciar uma fazenda brasileira maximizando lucro sem prejudicar o solo.

---

### 🔁 Loop do jogo

1. Plantar cultura
2. Escolher estratégia:

   * 🌿 Orgânico → lento + sustentável
   * ⚡ Químico → rápido + degrada solo
3. Aguardar crescimento
4. Colher
5. Vender
6. Reinvestir

---

### ⚙️ Regras principais

* Cada plantação gera moedas
* Solo possui qualidade (0 a 100)
* Uso excessivo de químico ↓ qualidade
* Solo ruim ↓ produção
* Orgânico recupera solo

---

### 🎲 Eventos aleatórios

* 🌧️ Chuva → acelera crescimento
* ☀️ Seca → reduz produção
* 🐛 Praga → reduz colheita

---

### 🧠 Aprendizado (diferencial)

Ao colher:
👉 aparece uma “Ficha do Produtor” com informação real

✔ isso bate forte no edital

# 💻 CÓDIGO PRONTO PRA REPLIT (HTML + JS)

👉 Cria um projeto → HTML/CSS/JS
👉 Cola isso no `index.html`

---

```html
<!DOCTYPE html>
<html>
<head>
  <title>Fazenda Brasil: Safra Inteligente</title>
  <style>
    body { font-family: Arial; text-align: center; background: #e8f5e9; }
    button { padding: 10px; margin: 5px; }
    .box { border: 1px solid #333; padding: 10px; margin: 10px; }
  </style>
</head>
<body>

<h1>🌾 Fazenda Brasil</h1>

<div class="box">
  <p><b>Moedas:</b> <span id="money">0</span></p>
  <p><b>Solo:</b> <span id="soil">100</span></p>
  <p id="status">Plante algo!</p>
</div>

<div>
  <button onclick="plant()">🌱 Plantar</button>
  <button onclick="organic()">🌿 Orgânico</button>
  <button onclick="chemical()">⚡ Químico</button>
  <button onclick="harvest()">🌾 Colher</button>
</div>

<script>
let money = 0;
let soil = 100;
let planted = false;
let strategy = "";

function updateUI() {
  document.getElementById("money").innerText = money;
  document.getElementById("soil").innerText = soil;
}

function plant() {
  planted = true;
  document.getElementById("status").innerText = "Plantado!";
}

function organic() {
  if (!planted) return;
  strategy = "organic";
  document.getElementById("status").innerText = "Modo orgânico selecionado";
}

function chemical() {
  if (!planted) return;
  strategy = "chemical";
  soil -= 10;
  document.getElementById("status").innerText = "Modo químico selecionado";
  updateUI();
}

function harvest() {
  if (!planted) return;

  let gain = 10;

  if (strategy === "chemical") gain += 5;
  if (strategy === "organic") soil += 5;

  if (soil < 50) gain -= 3;

  money += gain;

  let events = ["🌧️ Chuva ajudou!", "☀️ Seca prejudicou!", "🐛 Praga apareceu!"];
  let event = events[Math.floor(Math.random() * events.length)];

  alert(event);

  alert("📊 Ficha do Produtor: O Brasil é um dos maiores produtores agrícolas do mundo!");

  planted = false;
  strategy = "";
  updateUI();

  document.getElementById("status").innerText = "Colhido!";
}

updateUI();
</script>

</body>
</html>
```
